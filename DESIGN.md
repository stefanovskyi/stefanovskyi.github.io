# Design System Specification

## Brand Personality
Professional, modern, and data-driven with a clean, high-contrast aesthetic.

## Typography
The system uses a hierarchy of sans-serif fonts to ensure clarity and professional appeal.

- **Primary Heading Font:** `Mont SemiBold`
  - Used for main titles and page headings.
  - Characteristics: Bold, modern, geometric.
- **Secondary/Alternative Heading Font:** `Manrope SemiBold`
  - Used when `Mont` is unavailable or for specific sub-sections.
- **Sub-headings:** `Inter SemiBold`
  - Used for smaller headers and highlighting important text within descriptions.
- **Body Text:** `Inter Regular`
  - Used for large blocks of text, descriptions, and captions.
  - Characteristics: Highly readable, neutral.

## Color Palette

### Primary Colors
- **Orange (#FF5800):** The primary action and accent color. Used for buttons, highlights, and branding elements.
- **Black (#131725):** The main color for text and deep backgrounds. Provides high contrast.
- **Light Gray (#EEF4F5):** Used for subtle backgrounds and section dividers.

### Secondary/Data Colors
Used primarily for charts, graphs, and UI status indicators.
- **Yellow (#F7AD19):** Warm accent for data visualization.
- **Dark Blue (#053F5C):** Deep tone for primary data sets.
- **Blue (#429EBD):** Mid-tone for balanced visual interest.
- **Light Blue (#9FE7F5):** Soft accent for highlights and secondary data.

## Iconography
The system uses a cohesive set of custom line icons designed for clarity and a modern look.

- **Icon Style:** Outline/Line icons with a consistent stroke weight (4px for large 128x128px versions). 
- **Color:** Primary icons use the brand's Orange (#FF5800).
- **Categories:**
  - **Business & Logic:** Strategy (rocket), process (gears, factory), structure (org chart).
  - **User Interaction:** Profile, collaboration, communication (mail, chat), security (shield).
  - **Data & Planning:** Calendar, database, analytics (growth charts), presentation.
  - **Education & Growth:** Graduation cap, certificate, learning (book).
- **Usage:** Icons are used to support visual storytelling and should be placed with generous padding to maintain the clean aesthetic.

## Visual Elements
- **Charts and Graphs:** Utilize the full color palette to distinguish data points. Simple, clean lines and flat colors.
- **Spacing:** Generous white space is used to maintain a clean layout and emphasize content hierarchy.
- **Components:** Buttons and interactive elements should utilize the primary Orange for calls to action, ensuring they stand out against the high-contrast Black and Light Gray backgrounds.
